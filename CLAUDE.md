# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project structure

Two independent sub-projects that talk to each other over HTTP — no shared build system:

- `flutter_voice-master/` — Flutter app, "GearShield 2.0 - Deepfake & AI Voice Detector". Dart SDK `>=3.0.0 <4.0.0`.
- `python GearShield/` — FastAPI backend + audio-ML pipeline. **Directory name has a literal space** — always quote it in shell commands (`cd "python GearShield"`).

The Flutter app POSTs recorded audio to the Python backend at `http://127.0.0.1:8000` (see `flutter_voice-master/lib/services/gearshield_service.dart`). If the backend is unreachable, it falls back to a local on-device heuristic engine — the app never hard-fails without a backend. Android emulator needs `10.0.2.2` instead of `127.0.0.1`; that swap isn't currently wired in.

## Not a git repository

This directory has no `.git`. Don't assume `git diff` / `git log` / branch-based workflows are available.

## Running things

- Backend: `cd "python GearShield"` then `python main.py` (or `uvicorn main:app --reload`) — serves on `127.0.0.1:8000`.
- Backend tests: run directly as scripts, e.g. `python test_api.py`, `python test_detect_endpoint.py` (FastAPI `TestClient`-based; no pytest config in the repo).
- Flutter app: standard `flutter run` / `flutter build` from `flutter_voice-master/` — no custom scripts or Makefile.

## API contract

- `POST /detect` is a **fixed external contract** for the "Altur HackMTY26" hackathon benchmark (base64 stereo 8kHz WAV in, strict `{is_synthetic, confidence}` out). Don't change its request/response shape casually.
- `/analyze`, `/reconfirm`, `/generate-pdf`, `/stats`, `/logs` are the richer app-facing endpoints. `reports/logs_db.json` is a flat JSON file acting as the log "DB", not a real database.

## Data and model artifacts — do not touch without explicit request

`python GearShield/data/` (~5.3GB, ~33k audio files), `external_datasets/`, `dev-clean_mini.tar.gz`, and the trained model artifacts `gearshield_baseline.joblib` / `gearshield_engine.onnx` (also duplicated into `flutter_voice-master/assets/models/`) are large and are generated/regenerated by training scripts, not hand-edited. Never read, edit, delete, or regenerate these — and never run a broad recursive glob over `data/` — unless the user explicitly asks for it in that message. To retrain, use `/retrain-model`.

## Conventions

- Backend code comments, docstrings, and user-facing strings are in Spanish, as are the Flutter app's user-facing labels — match that for any new user-facing text.
- No `.dockerignore` exists next to the Dockerfile, so `COPY . .` currently pulls in the multi-GB `data/` directory into the image. Flag this if touching the Dockerfile rather than silently "fixing" it.
